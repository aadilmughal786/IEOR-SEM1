> [!tip]- Typing Efficiency Matters  
> In competitive programming, **typing speed and accuracy** can save crucial seconds, especially during tight contests.  
>
> - Use **snippets** or code templates to set up boilerplate code instantly.  
> - Practice with your preferred editor to build **muscle memory**.  
> - Master keyboard shortcuts in **VS Code** or your favorite IDE.  
> - Write **concise and readable** code to minimize unnecessary edits.  
> - Use `Ctrl + Backspace` to quickly delete entire words.  
> - **Touch typing** is the technique of typing **without looking at the keyboard**. Instead, you rely on **muscle memory** to find the keys based on their position.
> - [Monkeytype – A minimalistic, customizable typing test](https://monkeytype.com/)
>
> Even small improvements in typing can add up to a **competitive advantage**.
>

> > [!tip]- Finger Position & Home Row Technique  
> > - Each key on your keyboard is assigned to a specific finger, and you should use the correct finger every time. The picture below shows which keys are assigned to each finger.   
> > - You don’t need to memorize finger positions; just stay mindful of them during practice.  
> > - When you need to use the **shift** key, you should be using one hand for the letter and the other hand for the shift key.    
> > - **Always return fingers to the home row** (ASDF / JKL;) after each keystroke.  
> > - Of course, there are times when the same finger types two letters in a row. You should practice the common combinations without bringing your finger home,
> > - but the key to learning to **touch type** is training your fingers to instinctively move from the home row to the correct key.

> > [!tip]- Special Keys and Their Functions  
> > Learning the role of special keys can greatly enhance your typing speed and workflow — especially when combined with shortcuts or used in text editors.  
> >  
> > | **Key**          | **Primary Use**                                                                 |
> > |------------------|---------------------------------------------------------------------------------|
> > | **Shift**         | Capitalizes letters; accesses secondary characters (e.g., ! from 1); It is also used with the arrow keys to highlight text. |
> > | **Caps Lock**     | Toggles typing in all capital letters                                          |
> > | **Tab**           | Indents text or moves between form fields                                     |
> > | **Backspace**     | Deletes character to the **left** of the cursor or selected text              |
> > | **Delete**        | Deletes character to the **right** of the cursor or selected text             |
> > | **Home**          | Moves cursor to the beginning of the line                                     |
> > | **End**           | Moves cursor to the end of the line                                           |
> > | **Ctrl**          | Modifier key used in shortcuts (e.g., Ctrl + C); assists in text navigation   |
> > | **Alt**           | Used for alternate functions or system-level shortcuts                        |
> > | **Enter**         | Starts a new line or submits a form                                           |
> > | **Page Up**       | Scrolls up one screen or moves to top of the document                         |
> > | **Page Down**     | Scrolls down one screen or moves to bottom of the document                    |
> > | **Esc**           | Cancels actions or closes dialogs                                             |
> > | **Print Screen**  | Takes a screenshot of your entire screen                                      |
> >  
> > Mastering these keys helps boost productivity, especially in coding and writing tasks.
>
> ---
>
> > [!tip]- More Typing Tips (Accuracy First)
> >
> > - **Focus on accuracy**, not speed — aim for **97%+ accuracy**.  
> > - Concentrate on **entire words**, not individual letters. In the long run, focus on the **whole sentence**.  
> > - Maintain your **typing habit** even outside practice sessions.  
> > - **Practice regularly** to build muscle memory and consistency.  
> > - While typing the **current word**, begin processing the **next word** to avoid gaps.

> [!tip]- VS Code Setup for Development Tools  
> 
> | **Tool**       | **Description**                                                                 | **Setup/Installation**                                                                 |
> |----------------|---------------------------------------------------------------------------------|----------------------------------------------------------------------------------------|
> | **LSP**        | Language Server Protocol connects the editor with a language server for features like autocompletion, go-to-definition, and error diagnostics. | Install language-specific extensions (e.g., `C/C++` for C++, `Python` for Python).     |
> | **DAP**        | Debug Adapter Protocol enables debugging, allowing breakpoints, stepping through code, and inspecting variables. | Built-in support in VS Code; configure `launch.json` for language-specific debuggers. |
> | **Formatter**  | Automatically formats code to a standard style (e.g., PEP 8 for Python, clang-format for C++). | Install formatters like `Prettier`, `clang-format`, `black`, or configure format-on-save. |
> | **Linter**     | Analyzes code for errors, style violations, or bad practices (e.g., missing semicolons, unused variables). | Install linters like `ESLint` for JavaScript, `flake8` for Python, or `cppcheck` for C++. |
> 
> These tools will help you write, debug, format, and lint your code more effectively and efficiently in VS Code.
